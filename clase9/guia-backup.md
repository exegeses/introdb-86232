# guía para generar una copia de respaldo

1. ir a Server
2. seleccionar "Data Export"
Aparecen dos columnas, en la columna izquierda están todas las bases de datos. Puedo elegir una o varias
3. Seleccionar Base
Una vez que selecciono la base me van a aparecer todas las tablas de esa base. Puedo elegir una o varias tablas. De manera predeterminada se seleccionan todas las tablas
4. Seleccionar Tablas
En la parte inferior hay un bloque para elegir en qué archivo vamos a generar el backup
5. Marcar: "Export to Self Contained File"
Luego podemos elegir en qué directorio y con qué nombre generar el backup
6. En el desplegable elegir el tipo de backup
  - Estructura y Datos
  - Sólo Estructura
  - Sólo Datos
7. Start Export
